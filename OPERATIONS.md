## Architecture overview

All services run as native systemd units — no Docker on the production server.

```
Internet
   | HTTP :80 / HTTPS :443 / PostgREST :4000
   v
Apache2  (permomap.wilsonenv.nz)
   +-- /api/*   -> permomap-server  (localhost:3000)  - Express + Passport
   +-- /auth/*  -> permomap-server  (localhost:3000)  - OAuth callbacks
   +-- /*       -> /var/www/permomap  (static Vite build, Basic Auth)

Apache2  (:4000, public)  -> PostgREST  (localhost:4001)
                                +-- exposes api.* functions as REST RPC

Native systemd services
   +-- permomap-server.service  (node, port 3000, /home/acheronuser/permomap)
   +-- postgrest.service        (port 4001, /opt/postgrest/)
   +-- pg_featureserv.service   (port 8080, OGC API Features)
   +-- pg_tileserv.service      (port 8081, MVT vector tiles)
   +-- nzhgpa-api.service       (node, port 3001 localhost, /var/www/html/api)
   +-- postgresql               (port 7432 — non-standard, local only)
```

## Replication steps (bare server to running system)

### 1. Provision the VPS
- Ubuntu 24.04 LTS, minimum 2 vCPU / 4 GB RAM / 40 GB disk
- Point DNS A records: `permomap.wilsonenv.nz` and `geoserver.wilsonenv.nz` to VPS IP

### 2. Install system dependencies
```bash
apt update && apt upgrade -y
apt install -y apache2 certbot python3-certbot-apache ufw git curl wget \
               nodejs npm postgresql postgresql-postgis
```

### 3. Configure firewall
```bash
ufw allow OpenSSH
ufw allow 'Apache Full'
ufw allow 4000/tcp   # PostgREST public port
ufw enable
```

### 4. Clone the repository
```bash
git clone https://github.com/petergwilson/permomap.git /home/acheronuser/permomap
```

### 5. Configure Apache
```bash
cp /home/acheronuser/permomap/scripts/permomap.wilsonenv.nz.conf \
   /etc/apache2/sites-available/permomap.wilsonenv.nz.conf
a2enmod proxy proxy_http rewrite ssl headers
a2ensite permomap.wilsonenv.nz.conf
a2dissite 000-default.conf
# Obtain TLS certificates (DNS must resolve first)
certbot --apache -d permomap.wilsonenv.nz
certbot --apache -d geoserver.wilsonenv.nz
apachectl restart
```

### 6. Set up Basic Auth for the static site
```bash
htpasswd -c /etc/apache2/.htpasswd <username>
```

### 7. Configure PostgreSQL
PostgreSQL runs on non-standard port 7432. Edit `/etc/postgresql/*/main/postgresql.conf`:
```
port = 7432
```
Then restart: `systemctl restart postgresql`

### 8. Install and configure PostgREST
```bash
# Download latest PostgREST binary from https://github.com/PostgREST/postgrest/releases
mkdir -p /opt/postgrest
mv postgrest /opt/postgrest/postgrest
chmod +x /opt/postgrest/postgrest
# Copy unit file and config, then edit /opt/postgrest/postgrest.conf
cp /home/acheronuser/permomap/scripts/postgrest.service /etc/systemd/system/
systemctl enable --now postgrest
```

### 9. Install pg_featureserv and pg_tileserv
```bash
# Download binaries from https://github.com/CrunchyData/pg_featureserv
# and https://github.com/CrunchyData/pg_tileserv
cp /path/to/pg_featureserv /usr/local/bin/
cp /path/to/pg_tileserv /usr/local/bin/
cp permomap/scripts/pg_featureserv.service /etc/systemd/system/
cp permomap/scripts/pg_tileserv.service /etc/systemd/system/
systemctl enable --now pg_featureserv pg_tileserv
```

### 10. Start the Node.js backend
```bash
cp /home/acheronuser/permomap/.env.example /home/acheronuser/permomap/.env.production
nano /home/acheronuser/permomap/.env.production  # fill in SESSION_SECRET, OAuth credentials
cp permomap/scripts/permomap-server.service /etc/systemd/system/
systemctl enable --now permomap-server
```

### 11. Deploy the static client
```bash
cd /home/acheronuser/permomap
npm ci && npm run build
cp -r dist/* /var/www/permomap/
```

### 12. Verify
```bash
curl -I https://permomap.wilsonenv.nz/
curl https://permomap.wilsonenv.nz/api/get_session
curl http://permomap.wilsonenv.nz:4000/       # PostgREST root
```

## Routine operations

### Restart all services
```bash
systemctl restart permomap-server postgrest pg_featureserv pg_tileserv
```

### View logs
```bash
journalctl -fu permomap-server     # Node.js backend
journalctl -fu postgrest           # PostgREST
journalctl -fu postgresql          # Database
tail -f /var/log/apache2/permomap_error.log
```

### Update application code
```bash
cd /home/acheronuser/permomap
git pull
npm ci
systemctl restart permomap-server
npm run build && cp -r dist/* /var/www/permomap/
```

### Database backup
```bash
bash /home/acheronuser/permomap/scripts/backup-database.sh
```

### Renew TLS certificates
Certbot renews automatically via systemd timer. Manual renewal:
```bash
certbot renew --dry-run
certbot renew
apachectl restart
```
